A web-based university class routine scheduling system that automatically generates conflict-free weekly class schedules for all 8 semesters while managing classroom assignments, teacher availability, course types, and student batch sizes. The system must handle complex academic scheduling constraints including room capacity matching, lab-group division for large batches (25+ students), collision prevention for rooms/teachers, workload balancing, and minimizing unnecessary schedule gaps.

Core Functional Requirements
1. Input & Admin Management

Admin panel for managing:

Teachers (name, designation, availability, load)

Courses (semester, credit hours, theory/lab type)

Student batches with size (split labs automatically)

Classrooms with capacity and lab/theory types

Time parameters (periods, slot duration, working days Sun–Thu)

All data must be editable with validation (capacity mismatch warnings, duplicate entries, etc.)

2. Automated Routine Generation

AI/Algorithm-based schedule generator that:

Ensures no teacher conflict

Ensures no room conflict

Ensures no batch conflict

Matches classrooms based on capacity + course type

Automatically creates lab sections for batches > 25 students

Balances teacher workloads

Minimizes long gaps for students & teachers

Guarantees a clean 5-day routine (Sun–Thu)

3. Manual Editing

Drag-and-drop or form-based editing of:

Course times

Room assignment

Teachers

Real-time conflict detection: highlights conflicts in orange (#F57C00) with explanations

4. Filtering & Viewing Options (NEW)

The system must support instant filtering of routines by:

Teacher

Semester / Batch

Course

Day

Room

Lab vs Theory classes

Filtering updates the schedule view in real time, similar to Google Calendar search.

5. Export & Download Features (Enhanced)

Users can export schedules in multiple formats:

PDF


Teacher-specific routine download

Semester-specific routine download

Day-wise compact view download (Sun–Thu)

Export will maintain color coding and layout.

6. Schedule Visualization

Google Calendar–inspired UI

Routine date / semester session displayed at the top

Day names shown vertically on the left side

Hourly/time-slot grid layout

Color-coded:

Primary #1565C0 for regular classes

Secondary #2E7D32 for labs

Warning #F57C00 for conflicts

Accent #6A1B9A for special notes

Responsive design for web/tablets/mobiles

Hover tooltips showing teacher, room, course, batch

Design Style Guide

Fonts: Roboto / Inter

Background: #F8F9FA

Text: #212121

Clean, minimal, grid-based

Tabular forms for admin inputs

Modern UI similar to university systems like Banner

Smooth transitions / clear hierarchy
